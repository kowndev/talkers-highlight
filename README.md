> Make active speakers in Simple Voice Chat easier to identify.

Talker's Highlight is a client-side addon for Simple Voice Chat that provides visual indicators for players currently speaking. It is designed for busy multiplayer environments where locating the source of voice communication can be difficult.

> **Not intended for competitive gameplay. Always obtain server approval before use.**

## Features 

### Tracers 🔦

Displays a visual line pointing toward players who are actively speaking through Simple Voice Chat.

Useful for:

* Community events
* Large friend groups
* Public voice chat hubs

### Logger 📑

Records voice activity events, allowing you to see when players start and stop speaking.

### Highlighter 👓*(Coming Soon)*

Adds visual highlighting to active speakers, making them easier to identify at a glance.

## Requirements📃

* Minecraft **1.21.1**
* Fabric Loader
* Simple Voice Chat

## Installation  📥

1. Install Fabric Loader for Minecraft 1.21.1.
2. Install Simple Voice Chat.
3. Download the latest release of Talker's Highlight.
4. Place both mods into your `mods` folder.
5. Launch Minecraft.

## FAQ ❓

### Is this a standalone mod?

No. Talker's Highlight is an addon for Simple Voice Chat and requires Simple Voice Chat to function.

### Does this modify voice chat behavior?

No. The addon only provides additional visual information based on voice activity detected through Simple Voice Chat.

### Is this a client-side mod?

Yes. Talker's Highlight is intended to be installed on the client.

### Will all servers allow this mod?

Not necessarily. Some servers may consider features such as Tracers or Highlighter to be unfair gameplay advantages. Always check with server staff before use.
